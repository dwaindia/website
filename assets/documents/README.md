# Public Statutory Documents (`assets/documents/`)

This directory is reserved for **publicly approved** statutory registration certificates or society governance bylaws if DWA chooses to host direct PDF downloads in the future.

## Strict Publication Safeguards

- **Public files only:** Never place internal audit working papers, private donor correspondence, bank KYC sheets, or confidential beneficiary records in this folder or any public Cloudflare R2 bucket.
- **Suggested standardized filenames (when approved):**
  - `dwa-society-bylaws-384-1993.pdf`
