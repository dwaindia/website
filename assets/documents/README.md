# Public Statutory & Audit Documents (`assets/documents/`)

This directory holds **publicly approved** PDF certificates, society bylaws, FCRA registration orders, and annual Chartered Accountant audit reports linked from `accountability.html#downloads`.

## Strict Publication Safeguards

- **Public files only:** Never place internal audit working papers, private donor correspondence, bank KYC sheets, or confidential beneficiary records in this folder or any public Cloudflare R2 bucket.
- **Suggested standardized filenames:**
  - `dwa-society-bylaws-384-1993.pdf`
  - `dwa-fcra-renewal-010270166.pdf`
  - `dwa-audit-report-fy2024-25.pdf`
  - `dwa-audit-report-fy2023-24.pdf`
  - `dwa-audit-report-fy2022-23.pdf`
  - `dwa-audit-report-fy2021-22.pdf`
  - `dwa-audit-report-fy2020-21.pdf`
- Once a signed PDF is added here (or hosted in a public R2 bucket), replace the corresponding `PDF Pending Upload` tag in `accountability.html#downloads` with a direct `<a href="...">Download PDF</a>` link showing file size and issue year.
